# **HOW TO RUN**



## INSTALLING

##### Install python from [here](https://www.python.org). You must install python 3.6 or it will not work

#### 

## RUNNING THE .PY FILES

#### OPTION 1: Using the command line 

* ###### type "cmd" in the directory bar, then type "python ext.py" replace ext.py with the extension .py file

#### OPTION 2: using IDLE

* ###### open the extension .py file with IDLE. click "run" -> "run module"



## IMPORTING THE EXTENSION

##### Open Splash them click "load experiment extension(WIP)" select the .s2e file(or .json) and you should see the extension
